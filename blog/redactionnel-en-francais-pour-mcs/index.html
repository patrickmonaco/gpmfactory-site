Oracle Mobile Cloud Service  

Oracle Mobile Cloud Service (MCS) vous propose les services nécessaires à l’élaboration d’une stratégie complète en matière de développement et de distribution d’applications mobiles. Vous bénéficiez de tout ce dont vous avez besoin pour établir une stratégie mobile d’entreprise à l’aide d’outils et de services innovants reposant sur les identités.

Conçue pour améliorer la réactivité, accélérer la commercialisation et simplifier la mobilité d’entreprise tout en réduisant les coûts, la solution Oracle Mobile Cloud Service aide les développeurs à définir des API mobiles et à créer des applications mobiles qui se connectent rapidement et en toute sécurité aux systèmes d’entreprise. Elle offre aux responsables des activités les analyses approfondies requises pour prendre des décisions éclairées en fonction des données. Oracle MCS est l’un des principaux services de plate-forme cloud d’Oracle. Il relie les développeurs mobiles aux sources de données et leur permet de créer des expériences mobiles interactives de manière simple et intuitive.

A quoi sert Mobile Cloud Service ?  

Oracle Mobile Cloud Service (MCS) est l’offre Mobile Backend as a Service (MBaaS) d’Oracle. Grâce à MCS, les entreprises peuvent rapidement et facilement créer et déployer des applications mobiles évolutives, fiables et sécurisées, tout en permettant aux développeurs d’utiliser les systèmes informatiques existants sans recours au service informatique.

Voici les avantages dont vous bénéficiez avec MCS :

  • Une solution Mobile Backend as a Service (MBaaS) d’entreprise.
  • Des SDK clients faciles à utiliser pour les applications mobiles natives Android, iOS et Windows, ainsi qu’un SDK JavaScript pour les applications mobiles hybrides. Toutes les API de plate-forme sont établies via des appels REST uniformes. Toutes les applications clients peuvent donc les utiliser et ainsi créer un environnement de développement cohérent, facile à contrôler et à maintenir.
  • Un outil de développement rapide d’applications mobiles sans code appelé Mobile Application Accelerator, qui permet aux développeurs non professionnels de créer rapidement des applications mobiles sur leur appareil.
  • Un espace de stockage des données issues des applications mobiles dans le cloud et/ou dans vos systèmes informatiques, selon votre préférence.
  • Des données intégrées hors ligne afin que vos applications puissent être utilisées dans un environnement non connecté, avec une synchronisation ultérieure des données, lors du rétablissement de la connexion Internet.
  • Un moyen simple de créer une logique applicative personnalisée avec des API personnalisées utilisant les normes du secteur, telles que Node.js, JavaScript et RAML.
  • Des services de localisation qui fournissent une vue à 360 degrés des informations de localisation contextuelles afin de favoriser l’intérêt et la prise de décision des utilisateurs d’applications mobiles.
  • Une gestion utilisateur mobile simplifiée.
  • Des analyses mobiles personnalisées et automatiques pour obtenir un aperçu du succès de la stratégie mobile avec des rapports ad hoc à portée de main.
  • La possibilité pour les développeurs d’applications mobiles de simuler les données et de poursuivre sur leurs applications en attendant que les développeurs de services implémentent l’API finale dans JavaScript.
  • Les deux équipes travaillent en parallèle, pour un gain de temps et d’argent.
  • Un cycle de vie continu pour permettre à vos applications d’évoluer au rythme de la mobilité.

Pourquoi choisir Mobile Cloud Service ?  

Parmi les offres cloud actuelles, nombreuses sont celles qui correspondent tout simplement à des technologies existantes ayant été détournées de leur fonction initiale et intégrées au cloud sans faire l’objet de la moindre adaptation. A l’inverse, Mobile Cloud Service a été conçu et développé spécifiquement dans le but de tirer profit des opportunités offertes par le cloud. Par ailleurs, Mobile Cloud Service permet la gestion continue du cycle de vie, la gestion de l’API, l’intégration de la sécurité et de sa résolution, la gestion des versions et le déploiement facilité entre environnements (développement, préparation et production).

A qui s’adresse Mobile Cloud Service ?  

Mobile Cloud Service apporte des solutions aux principaux problèmes que rencontrent les différents services à l’échelle de l’entreprise.

  • Développeur d’applications mobiles

Les développeurs d’applications mobiles utilisent MCS pour préparer et tester les ressources nécessaires au fonctionnement de leurs applications. Ils peuvent ainsi choisir parmi les API de plate-forme MCS et les API personnalisées, tout en collaborant avec les autres membres de l’équipe en vue de créer d’autres API personnalisées.

  • Développeur de services

Un développeur de services peut réaliser les mêmes activités qu’un développeur d’applications mobiles. Par ailleurs, les développeurs de services écrivent le code JavaScript basé sur Node.js afin d’implémenter les API personnalisées requises par les développeurs d’applications mobiles. Ils créent également des API de connecteur pour la connexion aux systèmes d’entreprise, ce qui peut impliquer la mise en correspondance des utilisateurs et des rôles à partir de la solution MBaaS vers les autres modèles d’authentification et d’autorisation utilisés par les systèmes d’entreprise concernés.

  • Responsable de programme mobile

Le responsable de programme mobile doit veiller au bon déroulement de l’initiative mobile de l’entreprise. A l’aide des tableaux de bord et des analyses de Mobile Cloud Service, le responsable du programme mobile peut facilement déterminer l’usage fait des applications, des back-ends et des API, et répondre à des questions de type “Le degré de satisfaction des utilisateurs à l’égard de l’application est-il élevé ?” ou “Certains aspects de l’application semblent-ils poser problème aux utilisateurs ?”.

  • Architectes d’entreprise

Les architectes d’entreprise s’intéressent à la direction stratégique de l’initiative mobile, s’assurant que les implémentations tactiques répondent aux besoins stratégiques de l’entreprise. Ils déterminent également les stratégies de sécurité et autres stratégies d’environnement qui régissent le déploiement mobile. MCS propose un ensemble d’outils afin d’aider les architectes d’entreprise à effectuer ces tâches.

  • Administrateur de cloud mobile

L’administrateur de cloud mobile est responsable de la surveillance de MCS et de son bon fonctionnement général. MCS fournit également un tableau de bord de diagnostic complet afin d’aider l’administrateur dans la réalisation de ses missions et de traiter toutes les autres tâches d’administration, comme l’ajout ou la suppression d’utilisateurs.

Quelles sont les API fournies par Mobile Cloud Service ?  

Pour simplifier le développement d’applications mobiles, Mobile Cloud Service inclut les API intégrées suivantes :

  • Notifications Push
  • Données hors ligne/Synchronisation
  • Gestion des utilisateurs d’applications mobiles
  • Analyses
  • Stockage mobile
  • Gestion des appareils

Vous pouvez appeler ces API directement à partir de vos applications via les appels REST directs ou à l’aide des kits SDK de Mobile Cloud Service pour les plates-formes iOS et Android. MCS propose également un outil de conception d’API fiable afin de créer vos propres API personnalisées pour obtenir les données dont vous avez besoin.

Comment définir des API personnalisées ?

Mobile Cloud Service s’appuie sur des normes courantes afin de définir et d’implémenter les API. RAML (REST API Markup Language) permet de décrire l’interface de votre API mobile. Vous pouvez importer et exporter des documents RAML pour faciliter votre transition vers MCS. Avant d’implémenter l’API, créez votre code personnalisé JavaScript basé sur Node.js afin de mettre les données en forme pour optimiser les performances de l’application mobile. Vous pouvez également combiner les données de nombreuses sources en utilisant JavaScript et les connecteurs afin d’exploiter les systèmes back-end et de transmettre les données en toute sécurité.

Quels sont les clients mobiles pris en charge par Mobile Cloud Service ?  

Si votre client prend en charge l’appel des API RESTful, il est pris en charge par Mobile Cloud Service. Par ailleurs, MCS propose des kits SDK natifs pour iOS, Android et Windows, ainsi que les utilitaires Java pour Oracle Mobile Application Framework (MAF). Xamarin™ fournit un SDK pour les programmeurs C#. Le SDK JavaScript prend en charge Oracle JavaScript Extension Toolkit (JET, inclus avec MCS), ainsi que les structures JavaScript tierces. Enfin, vous pouvez utiliser Mobile Application Accelerator (MAX) pour créer votre application mobile sans avoir à écrire la moindre ligne de code.

Qu’est-ce que Mobile Application Accelerator et comment permet-il aux développeurs non professionnels de créer des applications mobiles ?

Mobile Application Accelerator (MAX) est une nouvelle fonctionnalité de Mobile Cloud Service qui permet aux développeurs non professionnels (comme les business analysts ou les utilisateurs chevronnés d’applications) de créer rapidement une application mobile sur leur appareil. Elle permet d’effectuer des tâches de développement sur navigateur, et ainsi de modifier, tester et publier des applications mobiles, le tout à partir d’une console de navigateur. Vous pouvez prévisualiser l’application avec des données en temps réel à l’aide de la console du navigateur, sans avoir à effectuer de déploiement vers des simulateurs d’appareil. Absolument aucune opération de codage n’est requise et le déploiement de l’application est un jeu d’enfant : il vous suffit de scanner le code QR sur votre appareil mobile pour déclencher le téléchargement de l’application.

Oracle Mobile Application Framework est-il inclus dans Oracle Mobile Cloud Service ? Quelles sont les limites ?

Votre abonnement Oracle Mobile Cloud Service comprend l’utilisation limitée d’Oracle Mobile Application Framework. Pour connaître les conditions exactes de cette utilisation limitée, reportez-vous au document “Oracle Platform as a Service et Infrastructure as a Service – Description de Public Cloud Service” sur la page du  contrat relatif aux services Oracle Cloud . En résumé:

  • Une application mobile développée à l’aide de MAF dans le cadre d’une utilisation limitée doit s’appuyer sur des API et notifications fournies par MCS.
  • Le client créant l’application mobile doit avoir un abonnement MCS actif.
  • Les clients peuvent créer de nombreuses applications pour un grand nombre d’utilisateurs : il n’existe pas de restriction.

Quels sont les IDE utilisables lors du développement à l’aide de Mobile Cloud Service ?

Même si vous utilisez l’IDE correspondant à la technologie sélectionnée pour développer votre application mobile, vous travaillez exclusivement à l’aide de Mobile Cloud Service via votre navigateur Web. Au moment d’écrire le code JavaScript personnalisé pour vos implémentations d’API, vous pouvez utiliser l’éditeur JavaScript de votre choix. Lors du développement d’applications mobiles, vous utilisez l’IDE correspondant à la technologie sélectionnée à cet effet.

D’autres solutions Oracle Public Cloud Services sont-elles requises au préalable pour Mobile Cloud Service ?

Non. Mobile Cloud Service peut exploiter et utiliser d’autres solutions Oracle Platform As a Service (PaaS) et Software as a Service (SaaS), mais il n’existe aucune obligation d’abonnement.

Qu’en est-il de la sécurité ?  

La sécurité est au cœur de la solution Mobile Cloud Service. Les applications mobiles ont automatiquement accès aux fonctionnalités de sécurité MCS via le back-end mobile, un regroupement logique de ressources pour une application ou un groupe d’applications. Le back-end mobile fournit, entre autres, la passerelle qui permet à vos applications d’accéder aux ressources MCS via une authentification de base et/ou OAuth 2.0. Toutes les ressources proposées par MCS sont donc protégées par défaut, comme le stockage dans les collections, les adresses d’API personnalisées et bien plus encore. L’octroi d’un droit est nécessaire pour accéder à ces ressources par l’intermédiaire de l’accès basé sur le rôle. MCS propage l’identité de l’utilisateur mobile dans les systèmes d’entreprise back-end, à l’aide de normes telles que Basic Auth, SAML 2.0 et les profils de jeton de nom utilisateur. Enfin, MCS peut s’intégrer à votre infrastructure de sécurité on-premise, par exemple Oracle Access Manager ou Active Directory, ce qui permet à l’application mobile d’effectuer une authentification avec les informations d’identification SSO de l’entreprise.

Quels sont les tarifs d’abonnement à Mobile Cloud Service ?  

Les tarifs actuels d’abonnement à Mobile Cloud Service sont indiqués dans l’onglet Tarifs. Ils reposent sur deux critères : les appels d’API et le stockage. Le nombre d’appels d’API et la quantité de stockage dont vous bénéficiez dépendent des conditions établies avec votre représentant Oracle. L’abonnement comprend également un nombre minimal d’appels d’API par mois, comme indiqué dans l’onglet Tarifs.

Que comprend l’abonnement à Mobile Cloud Service ?

Vous avez accès à un portail de développement et à un environnement d’exécution. Vous avez ensuite la possibilité de vous abonner à trois environnements, correspondant chacun à un type d’utilisation : développement, test et production. Vous êtes libre de vous abonner à autant d’environnements que vous le souhaitez, tout en gérant le cycle de vie complet de chacun d’entre eux.

Qu’est-ce qu’un appel d’API ?

Un appel d’API correspond à tout appel d’API et à toute notification entre l’application mobile et Mobile Cloud Service. Par exemple, si un utilisateur d’application mobile effectue cinq appels vers MCS et reçoit deux notifications Push sur une période de 24 heures, cela fait un total de sept appels d’API pour le jour concerné.

Les appels entre Mobile Cloud Service et les services back-end (comme Oracle Sales Cloud) sont-ils considérés comme des appels d’API ?

Non. Seuls les appels d’API ou les notifications entre MCS et les applications mobiles sont considérés comme des appels d’API. Les appels entre MCS et les services back-end ne le sont pas.

Comment le stockage est-il pris en compte et calculé ?

Le stockage correspond à la quantité de stockage de blocs dans MCS utilisée par des applications mobiles. Par exemple, si une application mobile télécharge dix images dont la taille est de 1 Mo chacune au sein d’une collection de stockage dans MCS, cela signifie que 10 Mo d’espace de stockage seront décomptés de l’abonnement.

Comment étendre la capacité ?

Vous pouvez étendre la capacité en achetant les packages d’appels d’API ou de stockage supplémentaires. Reportez-vous à l’onglet Tarifs pour plus d’informations.

Comment les appels d’API sont-ils calculés dans les différents environnements MCS ?

Le nombre d’appels d’API est calculé dans tous les environnements MCS, puis rapporté comme un seul et unique ensemble. Le nombre total d’appels d’API est ensuite comparé au nombre d’appels d’API auquel votre abonnement vous donne droit chaque mois. Par exemple, si, au cours d’un mois donné, les appels d’API suivants se produisent :

  • Environnement de développement : 5 000 appels d’API
  • Environnement de test : 100 000 appels d’API
  • Environnement de production : 500 000 appels d’API
  • Le nombre total d’appels d’API indiqué par Oracle pour le mois est 5 000 + 100 000 + 500 000 = 605 000 appels d’API.
