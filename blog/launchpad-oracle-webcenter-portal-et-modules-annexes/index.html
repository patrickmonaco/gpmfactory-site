Tableau no 1: Oracle Fusion Middleware 11gR1 Browser Certifications  

C’est le tableau principal qui indique les navigateurs certifiés.

La mention ALL dans la première colonne signifie que cela concerne tous les modules de la famille Fusion Middleware (FMW), et par conséquent WebCenter Portal (qui en fait partie)

Chaque version de FMW ajoute, éventuellement, le support de nouvelles versions de navigateurs qui se rajoutent à celles qui étaient déjà certifiées.

Par exemple 11gR1 (11.1.1.7+) : Pour la version 11.1.1.7 et suivantes, IE10 est désormais supporté. Il faut sous-entendre « EN SUS » des versions d’autres navigateurs qui étaient déjà supportées dans les versions de Fusion Middlware précédentes

Dans ce tableau, la mention du navigateur est indépendante de l’OS, comme cela est précisé à plusieurs reprises dans le tableau

Tableau no 2: Oracle WebCenter Portal and Discoverer 11gR1 - Third Party Client Certifications  

Ce tableau concerne le bon fonctionnement de Oracle WebCenter Portal avec Microsoft Office : Certification Microsoft Office integration

Le  fonctionnement complet de WebCenter Portal en relation avec MS Office dans un navigateur est sous l’emprise de trois paramètres :

  • L’OS du poste client  (uniquement Windows)
  • La version de Microsoft Office (parce que WebCenter Portal permet d’éditer un document Office directement depuis le navigateur, comme dans Sharepoint)
  • Le type de navigateur ainsi que sa version

Le tableau Oracle WebCenter Portal and Discoverer 11gR1 - Third Party Client Certifications  dresse donc les différentes combinaisons des trois paramètres mentionnés.

Comme pour le tableau précédent, cette liste doit être interprétée de la façon suivante :

Chaque version apporte une éventuelle certification supplémentaire ;

Ainsi, la version 11.1.1.7 et suivantes ( 11gR1 (11.1.1.7+) apporte le support de IE 10 EN PLUS des autres versions de navigateurs supportées déjà par les versions précédentes de WebCenter Portal.

Accessibilité  

Pour l’instant  Webcenter Portal respecte la norme WCAG dans sa version 1.0  ‘AA’ . A rewrite of Section 508 is currently underway and Oracle is an active participant in the committee that is effecting those changes.

Once this rewrite is complete, Oracle will evaluate how to uptake both the new section 508 and WCAG 2.0 which is now a W3C Recommendation. Source:  http://www.oracle.com/us/corporate/accessibility/policies/index.html

Sharepoint Connector  

The primary responsibility of the connector is to transfer and store documents, with their metadata, from the SharePoint library to WebCenter Content Server repository. The connector replicates upload, update, check in, check out, discard check out, and delete operations from SharePoint to WebCenter Content Server repository. Using the connector, you can perform the following tasks:

  • Configure connection settings.
  • Configure security settings.
  • Map SharePoint metadata.
  • Activate the connector.
  • Configure scope rules and conditions.
  • Perform data migration.

The Oracle WebCenter WSRP Producer for .NET is a collection of libraries that surface .NET applications and Web Parts as WSRP 1.0 or 2.0 portlets. This release supports the latest .NET 3.5 features such as AJAX and allows developers to code in .NET without coding against a .NET WSRP framework.

Oracle WebCenter WSRP Producer for .NET  

The  Oracle WebCenter portal’s WSRP Producer for .NET  provides a means for developers and administrators to service-enable new and existing ASP.NET applications through the Web Services for Remote Portlets (WSRP) standard. It also unlocks Web Parts to standards based portals by exposing them directly as WSRP components. Now enterprises can take advantage of departmental resources directly.

Leverage .NET developer expertise. Developers use familiar tools and APIs, such as Visual Studio and ASP.NET Web Parts. Deploy the same Web Part to SharePoint or WebCenter with no code change.
Use portlets in WebCenter, WebLogic Portal, WebCenter Interaction, Oracle Portal, and other WSRP compliant portals.
Support for advanced ASP.NET 3.5 controls.
Supports popular .NET web technologies, such as ASP.NET AJAX, WCF REST, and Silverlight.
